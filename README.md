# Pocket Signal Care

Create a responsive self-care web app called whitelabel, React + TypeScript, prepaid mobile operator theme, with a bottom tab bar (Home, My plan, Top up, Add-ons, Account, Support) and empty routed pages.

This project was built with [Lovable](https://lovable.dev).
